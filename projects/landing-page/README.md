# Demo landing page — «Дубовий лист»

Adaptive single-page landing for a **fictional** local coffee shop.
Pure HTML/CSS + a tiny bit of JS. No frameworks, no backend, no tracking.

> Clearly labeled as a demo. Not a real business and not a client case.

## Open locally

```bash
cd projects/landing-page
# any static server, or just open index.html in a browser
python3 -m http.server 8765
# then open http://127.0.0.1:8765
```

## Files

- `index.html` — structure and copy (Ukrainian)
- `styles.css` — responsive layout
- `script.js` — local-only booking form demo
- `screenshot.png` — preview render

## Stack

HTML5, CSS Grid/Flexbox, vanilla JS.
